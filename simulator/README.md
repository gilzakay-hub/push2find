# סימולטור צמיד – המחשב בתפקיד הצמיד

הסימולטור מפרסם את המחשב ב-Bluetooth LE כצמיד בשם `P2F-SIM`, עם אותו פרוטוקול בדיוק (`PROTOCOL.md`). האפליקציה בטלפון מתייחסת אליו כמו לצמיד אמיתי ולא צריכה שום שינוי.

## התקנה והרצה

```bash
pip install -r requirements.txt
pip install --no-deps bless==0.2.6
python wristband_sim.py          # חלון עם כפתור גדול
python wristband_sim.py --cli    # טרמינל בלבד (Enter = לחיצה)
```

הדרך הפשוטה: להוריד את הגרסה הארוזה מדף ה-Releases ב-GitHub. בהרצה מהקוד צריך Python 3.11 או 3.12, כי הגרסאות החדשות של ספריית ה-Bluetooth לא עובדות עם bless.

| מערכת | הערות |
|---|---|
| **Windows** | Bluetooth דלוק. ייתכן שהשם `P2F-SIM` לא יופיע ברשימה. זה בסדר, כי האפליקציה מזהה את הצמיד לפי ה-Service UUID, והוא יופיע ראשון ברשימה. |
| **macOS** | בהרצה הראשונה צריך לאשר גישה ל-Bluetooth עבור Terminal (System Settings ← Privacy & Security ← Bluetooth). |
| **Linux** | צריך BlueZ פעיל (`bluetoothd`). אם יש בעיית הרשאות מריצים עם `sudo`. |

## איך בודקים
1. מריצים את הסימולטור ומחכים לשורה הירוקה **Advertising as P2F-SIM**.
2. בטלפון: Push2find ← Pair wristband ← מקישים על המכשיר שמופיע.
3. כשהאפליקציה מציגה **Connected**, לוחצים על הכפתור הכתום (או על מקש רווח). הטלפון אמור לצלצל. לחיצה נוספת עוצרת.
4. כדי לבדוק את מצבי הליבה: נועלים את המסך, מעבירים את הטלפון למצב שקט, יוצאים מהאפליקציה ולוחצים שוב.

מה עוד אפשר לבדוק:
- **סוללה:** גוררים את הסליידר, והאחוז מתעדכן באפליקציה.
- **Identify:** מקישים בהגדרות האפליקציה על Identify, והטבעת בסימולטור מהבהבת בכחול.
- **חיבור מחדש:** סוגרים את הסימולטור. האפליקציה עוברת ל-Searching. מריצים אותו שוב, והאפליקציה אמורה להתחבר לבד.

## מגבלה ידועה
Windows ו-macOS עשויים להחליף מדי פעם את כתובת ה-Bluetooth שהמחשב מפרסם (מנגנון פרטיות). אם האפליקציה מפסיקה להתחבר מחדש אחרי זמן מה או אחרי הפעלה מחדש של הסימולטור, מצמידים שוב מהגדרות האפליקציה. לצמיד האמיתי תהיה כתובת קבועה, ולכן זו מגבלה של הסימולטור בלבד. בדיקות חיבור מחדש ארוכות כדאי לעשות על Linux או עם nRF Connect בטלפון שני.
